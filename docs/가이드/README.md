# 납품 문서 — 누가 무엇을 읽나

```text
받는 사람            읽는 문서
개인·일반 사용자      사용자-설치-가이드.md     깔고 띄우기. Docker 말고는 아무것도 필요 없다
관리자(한 번만)       관리자-DB올리기.md        **리눅스 서버**에 중앙 DB 를 세운다
                                              (윈도우 PC 는 그 문서의 부록 A)
만드는 사람           **납품판-굽기.md**         `-rdel-swp` 판을 굽는다
보내는 사람           **납품물-전달.md**         USB 없이 깃으로 보낸다(2 GiB 벽)
전체 그림            구조.md                   무엇이 어디서 도는가
```

> **왜 여기 있나** — 이 문서들은 2026-10-29 까지 `Desktop\electron-test\가이드\`
> 에만 있었다. 즉 **버전 관리 밖**이었다. 납품 문서가 추적되지 않으면 "고객이
> 받은 판" 과 "지금 글" 이 어긋났을 때 **무엇이 바뀌었는지 알 길이 없다.**
> 그래서 납품 가지(`enterprise-custom-p`)로 들여왔다.

## 이 묶음에 **없는** 것

```text
취약점-조치-결과.md        날짜 보고서다 — 그날의 사진이고 납품 문서가 아니다
README-CLEAN-INSTALL.md    깨끗한 PC 에서 다시 깔아 본 기록
windows-설치 검증 가이드.md  검증 메모
⇒ 셋은 `Desktop\electron-test\가이드\` 에 그대로 둔다
```

## ⚠ 고칠 때

```text
원본은 **이제 여기다.** `electron-test\가이드\` 쪽을 고치면 이 묶음과 갈린다.
  고친다      docs\가이드\<파일>        ← 여기
  그다음      커밋한다(납품 가지)
  필요하면    electron-test 쪽으로 복사해 둔다(그쪽은 작업 메모용이다)
문서 규칙     펜스 **짝** · 홀로선 CR **0** · 탭 **0**
             (저장소가 `core.autocrlf=true` 다 — 스크립트로 고칠 때 파일을
              읽어 줄끝을 맞춘다)
```

## lite 판은 다른 문서를 본다

```text
`LITE.md` (가지 `lite-p`) — lite 는 **서비스 일곱 · 로그인 없음 · DB 를 자기 PC 에**
  띄운다. 굽는 명령도 다르다(`robo-lite.cmd`). 이 묶음의 글은 **enterprise 납품**
  기준이라 lite 에 그대로 적용되지 않는다.
```

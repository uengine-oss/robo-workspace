# SBOM 과 오픈소스 검증

## 언제 쓰나

```text
① 구운 직후          굽기가 같은 실행에서 뽑지만, **다시 재는 것이 기본**이다
② 납품물을 내기 전   심사에 나가는 숫자다
③ **날마다**         우리가 아무것도 안 바꿔도 숫자가 움직인다 (아래 ⚠)
```

⚠ **"어제 0건이었다" 는 근거가 아니다.** 취약점 DB 가 날마다 갱신된다 —
2026-10-23 에 0 이던 것이 **10-26 에 5** 였다. 바뀐 것은 우리가 아니라 DB 였다.

## 두 단계로 돈다

```bash
# ① 구성품 + 취약점  (수 분 걸린다 · 이미지마다 scout 를 두 번 부른다)
python robo-workspace/scripts/sbom-release.py <릴리스폴더>

# ② 라이선스        (초 단위 · ①이 만든 cdx.json 을 읽는다)
python robo-workspace/scripts/sbom-licenses.py <릴리스폴더>
```

내는 것:

```text
<릴리스>/sbom/<이미지>.cdx.json    CycloneDX — 구성품
<릴리스>/sbom/<이미지>.spdx.json   SPDX — 같은 내용, 다른 형식
<릴리스>/sbom/INDEX.md             사람이 먼저 읽는 것 — 무엇이·몇 개·무엇이 남았나
<릴리스>/sbom/LICENSES.md          라이선스 집계 + **검토할 목록**
<릴리스>/sbom/SHA256SUMS           위 전부의 지문
```

## ⚠ 읽는 법 — 여기서 여러 번 틀렸다

### 취약점

```text
① **요약줄만 읽는다** — `vulnerabilities │` 가 있는 줄 하나다.
   꾸러미마다 나오는 줄도 **모양이 같아서** 같이 세면 수가 몇 배가 된다
② 합계가 0이 아니면 **어느 이미지·어느 꾸러미**인지 먼저 가른다.
   "우리가 굽는 것" 과 "밖에서 당겨 오는 것" 은 고치는 길이 다르다
③ `fixed_version: not fixed` 는 **두 가지 뜻**이다
     · 이 줄에 백포트가 없다 → **메이저를 올리면** 빠진다
     · 아직 고친 판이 안 나왔다 → **기다리는 것뿐**
   가려 읽지 않으면 고칠 수 있는 것을 못 고치거나, 못 고치는 것을 고치려 든다
④ 권고문의 "Fixed version" 이 **발행되지 않은 판**일 수 있다
   (실제로 tomcat-embed-core 10.1.58 이 그랬다 — Central 에 없었다)
   고치기 전에 **저장소 메타데이터로 있는 판을 본다**
⑤ 올림 예측은 **새 판 자신의 결함을 못 센다**
   (jackson 은 옛 7건이 걷히고 새 5건이 올라왔다)
   ⇒ **올린 자리에서 다시 잰다**
⑥ 묶음(BOM)을 **이름으로 짐작하지 않는다** — 권위 있는 목록을 받아 읽는다
   (netty 를 Boot 관리로 안 봐서 "20건" 이라 했는데 실제 43건이었다)
```

### 라이선스

```text
① **LGPL 을 GPL 로 세지 않는다.** 글자가 겹친다(`GPL-3` ⊂ `LGPL-3.0-only`).
   그렇게 세면 psycopg(LGPL-3.0)가 "강한 카피레프트" 로 잡힌다 — 거짓 경보
② **OS 꾸러미와 언어 꾸러미를 가른다.** 컨테이너 안 데비안 패키지는 수천 개가
   GPL 이지만 **같이 담은 것**이지 링크가 아니다. 검토 대상은 우리가 넣은
   `pypi`·`npm`·`maven`·`cargo` 다
   ⚠ `generic`(bash·openssl 따위)은 **언어 꾸러미가 아니다** — 섞으면 숫자를 못 읽는다
③ **"없다" 와 "못 읽었다" 를 가른다.** 이 릴리스는 언어 꾸러미 1,788개 중
   **591개(33%)만** 라이선스를 읽을 수 있었다. 보고서가 그 비율을 같이 적는다 —
   심사에서 "강한 카피레프트 0" 만 떼어 내면 **거짓말이 된다**
```

## 끝내기 전에 세는 것

```text
□ SBOM 파일 수 = 이미지 수 × 2 (cdx + spdx)  — 1:1 이 아니면 빠진 것이다
□ INDEX 의 이미지 수 = 매니페스트의 이미지 수
□ 못 읽은 이미지가 **하나라도 있으면 실패로 낸다**
   (빠진 채로 내면 "없다" 와 "못 읽었다" 를 심사에서 가를 수 없다)
□ LICENSES 의 "검토할 것" 이 비어 있는지, 비었다면 **읽은 비율**을 같이 적었는지
□ 숫자를 **문서에 박지 않는다** — 거둔 뒤에도 "남았다" 고 말하게 된다
   (10-22 판이 실제로 그랬다). 글은 "그 자리에서 센다" 고만 적는다
```

